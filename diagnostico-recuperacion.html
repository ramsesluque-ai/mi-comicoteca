Diagnóstico de colección anterior

Comprueba las bases de datos y las portadas locales de este sitio. No modifica ni elimina registros. El diagnóstico muestra únicamente cantidades y nombres de bases de datos, nunca títulos ni credenciales.

Pendiente de comprobación.

Si aparece una colección grande, pulsa «Descargar copia» en esa fila. Guarda el JSON y compártelo aquí si quieres que revise la migración. La copia de las portadas locales se tratará por separado.

Solo puede inspeccionar datos del dominio desde el que abres esta página. Si usaste otro dominio o perfil de navegador, debes abrir la página allí.
